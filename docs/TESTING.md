## 测试完成度评估

测试完后：

- **90%+ 通过** → ✅ 可作为 v1.0 Release
- **70-89% 通过** → 修关键 bug，作为 v1.0
- **< 70% 通过** → 推迟发布，继续打磨

---

## 收集的 Bug 怎么处理

发现 bug 后：

1. **严重（崩溃 / 数据丢失）**：立即修
2. **明显（功能不可用）**：列入 v1.0.1
3. **小问题（UI 错位）**：列入 v1.1
4. **优化建议**：列入 backlog
